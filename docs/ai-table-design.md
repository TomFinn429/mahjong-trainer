# AI 对局模式设计（feat/ai-table）

## 目标

1. 四人血战到底完整对局：你 + 3 家电脑，电脑分 入门 / 进阶 / 高手 三档。
2. 局势分析面板：每次轮到你时由程序计算（向听、有效牌、危险度、对手威胁），常驻显示。
3. 大模型讲解：填 API key 后，按需点击（或在关键时刻提醒后点击），流式输出讲解。

## 核心原则：引擎算，LLM 讲

调研结论（见 README「AI 对局」一节的出处）：通用大模型直接判断麻将牌效极不可靠
（13 张找听牌，o1 31%，GPT-4o < 9%）。因此：

- 出牌决策全部由规则引擎 + 电脑 AI 完成，LLM **不参与**任何决策。
- 分析器先算好每个候选打法的数值，LLM 只拿到这份 JSON 做解释。
- 系统提示要求 LLM 只引用给定数据；程序事后校验讲解中提到的牌是否都在候选列表中。

## 分层

```
src/core/mj-core.js     向听 / 有效牌 / 和牌判定 / 番型 / 计分（与训练器共用）
src/core/core.mjs       ES 模块包装
src/game/rng.mjs        可设种子的随机数（mulberry32）
src/game/rules.mjs      规则开关与默认值
src/game/engine.mjs     对局状态机：纯数据状态 + 事件日志 + 决定历史，可按种子重放
src/game/record.mjs     牌谱导出 / 重放校验 / 决策样本（格式见 docs/game-record.md）
src/ai/danger.mjs       危险度 / 对手威胁估计（电脑高手与分析器共用）
src/ai/bots.mjs         三档电脑
src/ai/analyzer.mjs     局势分析（只用玩家可见信息）
src/llm/providers.mjs   预置服务商
src/llm/client.mjs      OpenAI 兼容 Chat Completions + SSE 流式解析
src/llm/prompt.mjs      提示词构建与讲解校验
src/ui/table.mjs        对局界面
table.html              对局页面入口
server.js               零依赖本地服务：静态文件 + LLM 代理（仅监听 127.0.0.1）
```

信息隔离：电脑和分析器只拿 `viewFor(state, seat)`，看不到别家手牌和牌墙。

## 规则口径与来源（默认值，均可在 rules 中调整）

川麻**没有全国统一的权威规则**，各地、各平台说法不同。下表每条都写了三样东西：本项目的默认口径、找到的出处和原话、已知的变体。
实际打过之后想改口径，按这个顺序做：

1. 改 `src/game/rules.mjs`（开关、数额）或 `src/game/engine.mjs`（规则逻辑）；
2. 改下表对应行，并在「实测修改记录」里记一笔：改了什么、为什么改、依据哪个平台或牌桌；
3. 跑 `npm test`。规则改动会影响复式自对弈的结论，必要时重测 README 里的难度数据。

## 引擎接口

```js
const g = createGame({ seed, rules, dealer, humanSeat });
pending(g)            // { phase, seats: { [seat]: Action[] } } —— 当前需要谁做什么决定
submit(g, seat, act)  // 提交一个决定；所需决定齐了就推进，返回新产生的事件
viewFor(g, seat)      // 该座位可见的信息
```

阶段：`exchange`（换三张）→ `void`（定缺）→ `turn`（当前玩家：打牌 / 暗杠 / 补杠 / 自摸）
→ `claim`（他家响应：胡 / 碰 / 明杠 / 过）→ `robGang`（抢杠）→ `end`。

## 电脑难度

| 档位 | 打牌 | 碰杠 | 防守 |
|---|---|---|---|
| 入门 | 向听最小，平手随机；20% 概率在全部合法打法里随机 | 能碰就碰、能杠就杠 | 无 |
| 进阶 | 向听 → 有效牌（扣除可见牌） | 碰后向听变小才碰；杠不增加向听才杠 | 无 |
| 高手 | 进阶 + 听牌质量（剩余张数 × 番数）+ 一步前瞻（好形）+ 清一色倾向 | 同进阶 | 无（见下） |

危险度防守（攻守兼顾 / 弃和）在复式自对弈里没有带来收益，所以高手默认关闭，
代码中保留为可选项（`createBot(3, seed, { defense: true })`）。分析器的推荐与高手电脑同口径，
危险度和「对手威胁高」只作为参考信息显示。

用自对弈（固定种子）验证 高手 > 进阶 > 入门 的平均得分。工具：`tools/duplicate.mjs`。

## 危险度（估计值，界面明确标注「估计」）

- 对手已胡：不再有威胁。
- 对手缺门的牌：对该对手 **绝对安全**（川麻特有，最可靠的信息）。
- 可见张数（牌河 + 副露 + 自己手牌）达到 4：绝对安全。
- 其他：按牌的位置（中张 > 边张 > 幺九）、可见张数、对手威胁（巡目、副露数、是否已打完缺门）加权。
- 川麻没有振听，所以「对手打过的牌」**不**等于安全，这一点和日麻不同。
