## 期望得分统计（roadmap T12 第 1 步，2026-10-24，提交 b533593+改动）

工具 `tools/ev-stats.mjs`。两组牌谱各 4000 局：
**自对弈** = 四家高手（种子 110001 起 2000 副，pair）；**混合** = 高手、防守型、大牌型、速度型各一座（种子 120001 起 1000 副，field）。
取样是每次打牌之后的局面（缺门已打完），看这一家从这一刻到本局结束的结果；同一家同一局有多个样本，样本之间不独立，所以下面只报比例和均值，不报置信区间。
「得分变化」是从这一刻到本局结束这一家的分数变化，包括胡牌、点炮、杠钱、流局结算，单位是底分。
牌谱里的电脑都不弃和，真人对手会扣牌，所以和牌率是偏高的上限。完整表格用脚本重新生成即可。

两组数字很接近（下表写成「自对弈 / 混合」），说明这些结论对对手风格不敏感。

**1. 听牌后的和牌率主要看待牌剩余张数、牌墙剩余张数和还剩几家没胡**

| 听牌后待牌剩余 | 牌墙 40+ | 牌墙 20–29 | 牌墙 0–9 | 4 家未胡 | 2 家未胡 | 本局剩余平均得分 |
|---|---|---|---|---|---|---|
| 1–2 张 | 83% / 76% | 59% / 57% | 22% / 21% | 75% / 75% | 38% / 36% | +0.28 / +0.48 |
| 3–4 张 | 87% / 86% | 62% / 62% | 27% / 29% | 84% / 83% | 42% / 43% | +0.54 / +0.58 |
| 7–8 张 | 94% / 95% | 75% / 78% | 42% / 37% | 93% / 94% | 55% / 61% | +1.40 / +1.45 |

同样是 3–4 张待牌，开局听牌和到了最后 10 张才听牌，和牌率相差 3 倍以上。现在的综合分完全不看牌墙剩余和未胡人数。

**2. 「多门听」本身不加分，要看的是剩余张数**

待牌剩余同样是 3–4 张时，单门听 62.7% / 62.2%，两门听 63.1% / 65.3%；5–6 张时，两门 72.7% / 70.3%，三门以上 64.2% / 75.3%。
在剩余张数相同的条件下，门数多少没有稳定差别。多门听的好处，只来自它通常能留下更多张。

**3. 打点的价值：多 1 番，大约相当于多 4 张待牌**

| 听牌最大番 | 本局剩余平均得分（自对弈 / 混合） | 样本 |
|---|---|---|
| 0 番 | +0.34 / +0.30 | 40266 / 39853 |
| 1 番 | +0.95 / +1.10 | 16638 / 17781 |
| 2 番 | +2.05 / +2.26 | 6032 / 6433 |
| 3 番（封顶） | +2.42 / +3.20 | 1632 / 1964 |

0 番到 1 番约 +0.6 至 +0.8 分；待牌从 3–4 张增加到 7–8 张约 +0.86 / +0.87 分。
现在的综合分里，3–4 张待牌全部加 1 番只加 1 分左右（`0.5 × 剩余张数 × 0.5 × 番`），而多 4 张待牌加 6 分左右（有效牌 + 听牌加成），
**相对于实测，综合分把番数低估了大约 5 倍**。注意这是相关不是因果：番数高的手也可能在别的方面不同（例如清一色常伴随副露）。第 2 步要用模型控制这些因素后再确认。

**4. 向听的价值随巡目变大**

| 局面 | 牌墙 40+ | 牌墙 30–39 | 牌墙 20–29 | 牌墙 10–19 |
|---|---|---|---|---|
| 听牌 | +1.75 / +1.57 | +0.95 / +1.04 | +0.51 / +0.61 | +0.22 / +0.41 |
| 一向听 | +0.52 / +0.46 | −0.43 / −0.58 | −0.96 / −1.10 | −1.33 / −1.67 |
| 二向听 | −0.47 / −0.52 | −1.78 / −1.48 | −2.35 / −2.29 | −3.01 / −2.49 |

听牌与一向听相差约 1.2 分（开局）到 1.6–2 分（后巡）。综合分用固定的「向听 × 100」，不随巡目变化。

**5. 胡牌收入和点炮损失**

- 点炮胡收入就是 1 / 2 / 4 / 8 分（0 / 1 / 2 / 3 番）；自摸（含自摸 1 番）1 / 2 / 3 番平均收 3.55 / 6.58 / 13.25 分（自对弈），因为付钱的人数随未胡人数变化。
- 番种：平胡 84%、根 19%、断幺九 11%，清一色只有 2.3% / 3.4%，七对 2.2% / 1.8%，对对胡不到 1%。
- 点炮平均损失按胡牌者别家可见的副露分：门清 1.41 / 1.42，1 组副露 1.63 / 1.56，2 组以上多门 1.86 / 1.88，**2 组以上同一门 2.14 / 2.44**。清一色迹象明显时放炮代价约高 50%，可以用来给危险度乘上损失。
- 听牌后到本局结束前还会点炮的比例 23%，一向听 36%（电脑不弃和）。

**6. 流局很少**：每 4000 局只有约 230 / 420 人次参与流局结算；听牌者查大叫收入大约等于点炮收入（1 番 +2.27 / +2.08），未听牌者平均赔 2.9 / 3.1 分。查大叫在期望分里的权重很小。

## 期望得分模型（roadmap T12 第 2 步，2026-10-24，提交 b533593+改动）

- P(和)：逻辑回归（待牌剩余张数、牌墙剩余、未胡人数），听牌样本 130599 个；

## 封顶敏感性（roadmap T12 第 4 步，2026-10-24，提交 b533593+改动）

A = 高手（打牌和副露都按期望得分），B = 旧高手（`ev: false`）；三种规则用同一组种子 200001 起各 1000 副（pair），**权重没有重新拟合**（仍是 3 番封顶牌谱拟合的）。

| 规则 | 优势 | 每副标准差 | 优势 ÷ 标准差 |

| 3 番封顶 | **+0.512 ± 0.246** | 3.97 | 0.129 |
| 4 番封顶 | **+0.626 ± 0.308** | 4.97 | 0.126 |
| 不封顶 | **+1.094 ± 0.472** | 7.62 | 0.144 |

结论：

- **roadmap 原验收「4 番或不封顶时清一色 / 七对占比明显高于 3 番封顶」没有达到**：清一色 7.9% → 8.2%，七对 4.8% → 4.1%（约 2700 次胡牌，七对的差在噪声范围内，标准误约 0.56 个百分点）。

- 调整幅度有限的另一个原因：期望得分只在一向听以内起作用，「往哪条路线做」多在二向听以上就定了，那里还是和封顶无关的综合分 + 清一色倾向。
