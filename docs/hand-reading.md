# 读牌：从别家打出的牌推断他手里的牌型

这份文档写给练牌的人。内容分三部分：

1. 读牌要回答哪几个问题，依据是什么；
2. 每一步人脑怎么做，程序又怎么做；
3. 读牌结果怎么换算成「这张牌值不值得打」的期望得分，以及实测下来它值多少分。

文中所有数字都来自本项目的自对弈牌谱，具体口径见文末「实测」。程序实现在 `src/ai/infer.mjs`，任务说明见 `docs/roadmap.md` 的 T13。

## 一、读牌要回答的问题

| 问题 | 为什么重要 | 主要依据 |
|---|---|---|
| 他手里还有没有缺门牌 | 有缺门牌就不能胡，你打什么都安全 | 定缺 + 最后一张出牌（**硬规则**） |
| 他暗手里三门花色各占多少 | 决定你哪门牌危险、你要的牌是不是被他扣着 | 非缺门出牌的花色分布、副露、场上可见张数 |
| 他是不是在做清一色 | 点清一色要赔 4 倍 | 副露同门、那门一张不出、另一门在打 |
| 他听牌了没有 | 没听牌就不会点炮给他 | 巡目、副露数、缺门打完了没有、手切 / 摸切节奏 |
| 点给他要赔多少 | 同样的放炮概率，代价可以差 3 倍 | 上面几条合起来 |

川麻和日麻读牌最大的两点不同：

- **没有振听**：对手自己打过的牌，他照样可以胡。日麻里最可靠的「现物」安全牌，在川麻里只能降低一点危险，不能当安全牌用。
  实测也一样：他打过某张牌，手里还有这张牌的概率约降到 0.59 倍（见「牌张位置」），远不到 0。
- **缺门是最强的信息**：对手缺门花色的牌对他绝对安全，而且这是规则保证的，不是推断出来的。

## 二、专家看哪些原始资料

牌桌上能看到的信息，按价值从高到低：

1. **定缺**：开局就公开。
2. **牌河顺序**：哪张先打、哪张后打。早巡打出的中张（3–7）说明他放弃了这门。
3. **手切 / 摸切**：打出的是不是刚摸到的那张。本项目牌河里底色发灰的牌是摸切。
   连续摸切，说明摸到的牌都没用，手牌可能已经成形（听牌或接近听牌）；手切说明他在调整手牌。
4. **副露**：碰了什么、碰了几组、是不是同一门。
5. **场上可见张数**：你自己的手牌 + 所有牌河 + 所有副露。某门看得见的越多，别人手里这门就越少。
6. **换三张**：你收到的三张来自某家，他不要这门的可能性较大。不过定缺一公开，这条信息基本就被覆盖了。
7. **巡目 / 牌墙剩余**：越往后，听牌的可能越高。

文献与工具（方法可以借鉴，数字不能照搬）：

- とつげき東北《科学する麻雀》：用大量牌谱统计「什么迹象下对手听牌 / 做什么」的思路。本项目所有数字都是这样从牌谱统计出来的。
- ネマタ《現代麻雀技術論》：读牌部分对「手切 / 摸切」「早巡打出的牌」的整理。
- Mizukami & Tsuruoka（2015, IEEE CIG）：把对手建模拆成「听牌概率、待牌、打点」三个子模型，再组合进决策。本项目的结构和它一致。
- Suphx（arXiv:2003.13590）、Mortal：用最终得分做目标，衡量一个特征「值不值钱」。
- 本项目：练习模式下的「先猜后揭晓」、局终摊牌对照、`明牌` 开关（复盘用）、`tools/fit-infer.mjs`（用牌谱检验读牌准不准）。

## 三、一步一步怎么读

### 第 0 步：先数牌

把你看得到的牌按种类数一遍：自己手里的、四家牌河里的、所有副露里的。看不见的牌才可能在别人手里或牌墙里。程序里这一步是 `visibleCounts`。

### 第 1 步：缺门（硬规则）

规则要求：手里有缺门牌时，必须先打缺门牌。所以：

> **只要他最近一张出牌不是缺门，他手里就一定没有缺门牌。**（例外：轮到他、刚摸到缺门牌还没打的那一刻。你自己做决定的时候，对手都不在这种状态。）

这条在 8000 局牌谱里没有一个反例（`tools/fit-infer.mjs` 会检查）。原来启发式的「最近 3 张都不是缺门」过于保守了。

缺门打得慢的人，起手缺门牌多、另外两门少，进度也慢。如果最近一张还是缺门，他手里可能还有，模型会按连续打缺门的张数估计。

### 第 2 步：花色比例

人脑的做法：

- 看非缺门出牌里哪门打得多。打得多的那门，他留得少。这是权重最大的一条。
- 早巡打出的中张，说明那门不要了。
- 某门场上看得见的越多，别人手里这门就越少。
- 碰了某门，那门至少有 3 张在用。

程序的做法：条件 logit。每门花色算一个分数，再归一化成「暗手每张牌属于这门的概率」。系数（`infer-weights.mjs`，正数表示更可能在他手里）：

| 特征 | 系数 | 读法 |
|---|---|---|
| 这门是缺门（还没打完） | −3.00 | 缺门牌只是残留，比例很小 |
| 非缺门出牌里这门的占比 | −0.97 | 打得多 → 留得少（最强的一条） |
| 场上可见这门的比例 | −1.09 | 看得见的多 → 别人手里少 |
| 最近 4 张里这门的张数 | +0.12 | 最近还在打这门，说明手里还有这门（拆的是边角） |
| 打出的这门中张数 | −0.10 | 打中张 = 放弃这门 |

**例 1**：下家缺万，打完 3 张万之后，条子打了 5条、3条、7条，筒子一张没打，没有副露。
程序推断：暗手大约 **筒 70%、条 30%**，清一色 7%，听牌 44%。依据会逐条列出：

```
缺万已打完（最后一张不是缺门，规则保证手里没有缺门牌）
非缺门出牌：条 3 张、筒 0 张
早巡打过中张 5条 3条 7条（这门可能不要了）
最近 4 张里 2 张是手切（手牌在调整）
推断主花色：筒（约占暗手 70%）
```

注意，即使条子打了 3 张中张，条子仍然占 30%。实际牌谱里，单看出牌就断定「他只剩一门」通常会错。

### 第 3 步：清一色

牌谱里，某个时刻「暗手 + 副露最多只有 1 张不在主花色」的情况约占 3.3%，这是基础概率。迹象要很强才值得认定：

- 主花色比例很高（第 2 步）；
- 副露都在主花色（每组 ×e^1.44 ≈ 4.2 倍几率）；有一组不在主花色，几率 ×0.41；
- 主花色在牌河里出现得越少越像。

**例 2**：例 1 的下家又碰了 3筒、7筒，接着摸切了 2条、8条。
程序推断：清一色从 7% 升到 **53%**，听牌 77%。

### 第 4 步：听牌

主要看巡目、副露数、缺门打完了没有、最近的出牌。程序用学习型听牌模型（`danger-model.mjs`），测试集 AUC 0.89。
人脑可以记住：缺门没打完 → 基本没听；两组副露 + 10 巡以后 → 多半听了。

### 第 5 步：点给他要赔多少

放炮损失模型（泊松回归，`E[损失] = exp(Σ 系数 × 特征)`）的主要系数：

| 特征 | 倍数 | 读法 |
|---|---|---|
| 清一色概率 × 这张牌在他主花色 | e^1.47 ≈ **4.3 倍**（清一色概率为 1 时） | 点清一色家同门的牌最贵 |
| 每一组杠 | 合计约 1.7 倍（副露 +0.20、杠 +0.35） | 杠就是一根，翻一番 |
| 每一组碰 | 约 1.05 倍 | 碰本身不贵，贵在它暗示的牌型 |
| 只剩 1–2 张暗手（金钩钓迹象） | e^0.43 ≈ 1.5 倍 | |

例 2 里，点他一张 5筒的预期损失是 **3.62 分**，点 5条是 **1.63 分**。同样是放炮，代价差了一倍多。
原来的期望得分里，这一项写死成 1.6 分。

### 第 6 步：换算进期望得分

一个候选打法的期望得分（本项目 `ev.mjs` + `analyzer.mjs`）：

```
EV(打 X) = 打完后手牌的期望得分（和牌率 × 胡了平均收入 + 校准项）
         − Σ 每个对手 [ P(X 点给他) × 点给他的预期损失 ]
```

- 第一项用的和牌率，读牌版（开关 `evLive`，默认关闭）多考虑一件事：**你的待牌有多少被对手扣在手里**。
  比如你听 5筒，而下家在做筒子清一色，看不见的 5筒就更可能在他手里，而不是在牌墙里。拟合出来，这个比例每增加 1，和牌几率乘 e^−1.34 ≈ 0.26。
- 第二项就是第 5 步。放炮概率来自学习型放炮模型，损失来自读牌。

分析面板「危险」一列下面的「代价」就是第二项，「扣后」是扣掉它之后的期望。排序仍按高手电脑的口径（不扣），原因见下面的实测。

### 第 7 步：知道读牌的局限

- **具体到哪一张牌，信息很少**。同一门里，按「他打过这张 / 打过邻牌 / 是不是幺九」修正，只比「按看不见的张数平均分」好 0.4%（交叉熵 2.086 → 2.076）。
  原因还是没有振听：川麻里打过的牌不能说明他不要这张。读牌在川麻里主要读的是**花色**和**牌型**，不是具体哪张。
- 模型是从电脑对局里学的。真人的打法（尤其是大牌倾向、弃和习惯）不一样，数字会有偏差。
- 读牌准了，不等于打得更好。见下面的实测。

## 四、怎么练

1. 打开对局页的「练习模式」。对手每打一张牌，分析面板里他的那一栏会先藏起威胁和推断，让你选：主花色、清一色是 / 否、听牌是 / 否。没选的项不计分。
2. 点「揭晓推断」，对照程序的结论和依据。注意它列出的每条依据，在牌桌上都能直接看到。
3. 局终对照真实手牌：本局每次猜测里你和程序谁对谁错，以及累计命中率（存在本机浏览器里）。
4. 练习目标：主花色命中率追上程序（测试集上程序是 66%）；清一色和听牌先追求「不漏掉明显的」。

建议的练习顺序：先只猜主花色，熟练后再加上清一色和听牌。缺门的硬规则先背下来，它不需要猜。

## 五、实测（2026-10-28）

训练牌谱：混合对手池（高手、防守型、大牌型、速度型）4000 局（种子 210001 起）+ 高手自对弈 2000 局（种子 220001 起）。
测试牌谱：混合对手池 2000 局（种子 230001 起），没参与拟合。结果用 `node tools/fit-infer.mjs check work/infer/test-field.jsonl` 复现。

| 模型 | 基线 | 模型 |
|---|---|---|
| 花色分布（每张暗手牌的交叉熵） | 可能的花色平均分 0.913 / 按看不见张数分 0.884 | **0.769** |
| 各门张数绝对误差之和 | 5.64 张 | **3.31 张** |
| 主花色命中率 | — | 66.1% |
| 牌张位置（同门内交叉熵） | 按看不见张数分 2.086 | 2.076（几乎没有提升） |
| 清一色 AUC | 原启发式命中率 29.7%、召回 29.8% | **0.877**，分桶校准最高一档预测 21.4% / 实际 21.1% |
| 放炮损失平均绝对误差 | 常数 1.6：0.942 | **0.870**；最高一档预测 4.03 / 实际 3.90，最低一档预测 1.44 / 实际 1.18 |
| 和牌率对数损失（听牌） | 同批数据重拟合的原模型 0.5474 | 加「待牌在对手手里的比例」**0.5424** |

放炮损失整体偏高约 8%（预测平均 1.96，实际 1.81），原因是训练集里自对弈的牌更大，测试集只有混合对手池。

**对胜负的影响**（复式自对弈，对手池为大牌型 + 速度型）见 `docs/experiments.md`「读牌」一节。
简单说：读牌让分析面板更有解释力，但把它放进电脑高手的决策里，**没有测出收益**。
这和 `docs/experiments.md` 里「防守没有收益」的结论一致。在血战到底里，放炮不会结束你自己的手牌；
而点炮的局面里，大部分是必须先打的缺门牌，或者自己已经听牌在对攻，能靠读牌避开的本来就少。
所以对你来说，读牌最有用的地方是：**判断谁在做大牌、哪门牌贵**。至于「为了安全拆牌」，在这套规则下很少划算。
